Full homepage for direction E, the Vectorlab technical handbook, for visitors who navigate, search and cite.

Use theme `vectorlab`. The consumer supplies topics, notes, experiments (id, status, date, model, stack, finding) and project architecture data; the page renders the diagrams, filters and search palette from those arrays. Use `ink-soft` for small secondary text. Do: keep category colours as small indicators. Don't: add colour badges for skills, gradients or card-heavy layouts.
