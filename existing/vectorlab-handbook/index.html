    engineering / agents / harborUpdated 2026-10-02

    Harbor: a durable runtime for tool-using agents

    Every tool call is an event in an append-only log. A crashed run replays the log and resumes at the exact step, and approval gates pause a run without holding a worker.

    harbor/runtime/step.ts
    // Append the request first, so a crash never loses a call.
export async function runStep(ctx: RunContext, step: Step) {
  const call = await ctx.log.append({ type: "tool.requested", step });
  if (step.requiresApproval) await ctx.waitForApproval(call.id);
  const result = await ctx.tools.invoke(step.tool, step.args, { key: call.id });
  return ctx.log.append({ type: "tool.completed", callId: call.id, result });
}

    About the studio

    /about

    An independent engineering research studio.

    Vectorlab builds small systems, measures them, and writes down what happened. The work sits between product engineering and applied research: agents, retrieval and the infrastructure that keeps them dependable.

    Findings are published with their methods and their failures, so they can be checked and reused.
