    Beyond the Prompt: Building Reliable Agentic Systems

    AbstractWe traced 312 failed agent runs and found 54% broke at the boundary between a model and a tool, not in the model's reasoning. Four contracts enforced at those boundaries raised success on 30-step tasks from 41% to 83%.
    // contract 2: every tool result is validated before the model sees it
const result = await callTool(call, { timeoutMs: 8000 });
if (!schema(call.tool).safeParse(result).success) {
  return retryWithError(call, "result did not match schema");
}
